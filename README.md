# JANKEN / Remote Match

ルームIDを共有して、離れた相手とブラウザで遊べる1対1のじゃんけんアプリです。

## 使い方

1. 「ルームを作る」を押します。
2. 表示された6文字のルームIDを相手に共有します。
3. 相手は「ルームに参加」へIDを入力します。
4. 15秒以内にグー・チョキ・パーを選択します。両者が選択すると、すぐに手と勝敗が表示されます。

## GitHub Pagesへの公開

1. このフォルダーのファイルをGitHubリポジトリのルートへプッシュします。
2. GitHubの **Settings > Pages** を開きます。
3. **Deploy from a branch** を選び、公開したいブランチのルート（`/ (root)`）を指定します。
4. 発行されたURLを開きます。

`index.html` がルートにあるため、ビルドは不要です。HTTPSで公開されるGitHub Pagesからそのまま利用できます。

## 通信について

GitHub Pagesは静的ホスティングのため、対戦データの中継サーバーをアプリ内には置いていません。PeerJSの公開シグナリングサーバーでブラウザ同士を接続し、対戦中の手はP2P接続で交換します。ルームIDはホストが発行する一時的なPeer IDです。ページを閉じるとルームは終了します。
