# JANKEN TABLE / Card Battle

ルームIDを共有して、2〜4人で遊べるカード式じゃんけんボードゲームです。

## 使い方

1. ホームの「あそびかた」で流れを確認できます。
2. ホストが「テーブルを作る」を押し、プレイ人数・制限時間・ゲーム形式を決めます。
3. 表示された6文字のルームIDを共有し、参加者が「テーブルに参加」へ入力します。
4. 設定した人数がそろうと、ホストだけがゲームを開始できます。
5. 親から順に投票カードを裏向きで置き、全員でカードを選んでじゃんけんします。
6. 3枚以上の同じマークの連番カードはまとめて出せます。敗者は同じマークの場を回収し、勝者は出したカードを場へ置きます。
7. 誰かの手札が0枚になると決着し、残り手札がマイナス点になります。

## GitHub Pagesへの公開

1. このフォルダーのファイルをGitHubリポジトリのルートへプッシュします。
2. GitHubの **Settings > Pages** を開きます。
3. **Deploy from a branch** を選び、公開したいブランチのルート（`/ (root)`）を指定します。
4. 発行されたURLを開きます。

`index.html` がルートにあるため、ビルドは不要です。HTTPSで公開されるGitHub Pagesからそのまま利用できます。

## 通信について

GitHub Pagesは静的ホスティングのため、対戦データの中継サーバーをアプリ内には置いていません。PeerJSの公開シグナリングサーバーでブラウザ同士を接続し、ホストがルーム状態を管理して参加者へ配信します。ルームIDは一時的なPeer IDで、ページを閉じるとルームは終了します。

## 回帰テストケース

判定と同期の確認用に `test-cases.js` を用意しています。通常のグー対チョキ、3種類のあいこの最大・最小数字、複数勝者・複数敗者、連番カードの有効性、投票後の同期状態（投票フェーズ・人数・初期手札・場の枚数）を確認します。判定関数はブラウザ上の `window.__jankenRules` から実装と同じものを実行できます。
